Work for Video Games

Quest of Peril

    Prompt:

  • To create a fun RPG game in only nine weeks.

    • Problem:

  • Creating a functional and fun game in very limited time.

    • Role(s): Concept designer and 2D artist

  • Consulted with the team leader to create an atmosphere for the game.
  • Created all 2D assets (characters, animations, backgrounds, and UI).
  • Completed project in nine weeks.
  • Collaborated with two team members.

   
                 

    Process:

  • Designed the main character and began pixel animations for him.
  • Designed and created UI (title, textbox, buttons, icons, screens, and credits).
  • Created other characters like the main villain.
  • Made the various backgrounds and buildings.

               

Reflection:

-Helped me learn what goes into making video games.

-Taught me how to balance aspects of a project, as some things were needed prior to others.

-Better at collaborating and balancing work between team members.
