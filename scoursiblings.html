Work for Video Games

Scouring Siblings

    Prompt:

  • To create a fast-paced game that supported chaotic co-op gameplay in only six weeks.

    • Problem:

  • Creating a functional and fun game in very limited time.

    • Role(s): Concept designer and 2D artist

  • Conceptualized game idea, being inspired by Overcooked.
  • Created all 2D assets (characters, cutscenes, and UI).
  • Completed project in six weeks.
  • Collaborated with three team members.

 
                 

    Process:

  • Designed simple characters for our 3D modeler.
  • Designed and created UI (title, level select, controls, pause, game over, and victory screens).
  • Made intro cutscene so the player understands the story behind the gameplay.

               

Reflection:

-Deepened understanding on crafting a narrative for interactive storytelling.

-Learned about putting focus on player experience.

-Better at creating detailed stories.
